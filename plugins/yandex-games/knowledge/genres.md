# Жанровые плейбуки: что продаёт игру на странице Яндекс Игр

Источник жанра — `yandex/profile.json` (`facts.genreSignals` от `ygtool profile` + `game.*`, которые агент
заполняет после изучения кода, сцен, скриншотов и видео). Плейбук — отправная точка, а не шаблон: продающие
моменты берутся из РЕАЛЬНОЙ игры (что видно на кадрах), а не из этого списка. Гибридам — смешивай.

Категории — только из фиксированного списка консоли (см. lessons.md: Аркады, Боевики, Головоломки,
Гоночные игры, …); в таблице — типичный выбор.

Общее для всех жанров:
- Первые 1–2 с видео и первый скриншот — самое яркое и понятное: что делает игрок и почему это весело.
- Скриншот = геймплей ≥70% кадра, без меню/загрузки/рекламы/дебага; разнообразие (уровни, локации, режимы).
- Иконка/обложка — НЕ скриншот (5.6): постановочный арт, главный герой/объект крупно, читается в 64 px.
- Видео — монтаж коротких моментов (2–4 с, 5–10 штук, ≤27 с), без длинной ходьбы/ожидания/загрузок.
- Тексты: `howToPlay` описывает управление для КАЖДОЙ платформы из config.platforms (ПК и тач).

## Как найти моменты на собственном видео (любой жанр)
1. Листы кадров раз в 1 с (`ffmpeg ... fps=1,tile=10x6`), просмотреть все.
2. Отметить кадры, где на экране ИЗМЕНЕНИЕ: эффект, рост, победа, столкновение, новая локация/объект.
3. Каждому моменту — 2–4 с, начало за 0,5–1 с до пика. Порядок: самый яркий → разнообразие → сильный финал.
4. Сверить с `game.avoidInMedia` и общими запретами (загрузки, реклама, меню, смерть, засветки).

## Подстройка под сложность проекта (`game.complexity`)
- Force Binary сцены → только локализация через рантайм-словарь (LocYG), правки сцен руками в Unity.
- Pointer lock (FPS) → проверка выхода по Esc, курсор после рекламы.
- Нет тача при config.platforms ∋ mobile → блокер или убрать mobile.
- Большой проект/много ассетов стора → сначала `webgl-size`, потом медиа.
- Мультиплеер (Photon/Mirror) → оговорка в тексте, проверка без сети; .io-боты = «онлайн» нельзя обещать.
- Чужие бренды (`facts.brandRisk`) → предупредить пользователя до текстов/арта, решение за ним.
