# Требования Яндекс Игр к материалам (сверено 2026-10-15)

Источники: https://yandex.ru/dev/games/doc/ru/console/add-new-game/draft ,
https://yandex.ru/dev/games/doc/ru/concepts/requirements .
Актуальные цифры всегда приоритетнее брать из формы черновика (п. 5.3 требований).
Актуальность: `ygtool reqs-check` сравнивает страницы из `sources.json` со снимками в `snapshots/`
(полный текст требований по пунктам — `snapshots/requirements.txt`). При изменениях обнови этот файл и дату выше.

## Тексты (на КАЖДЫЙ язык из списка игры)
| Поле | Лимит | Правила |
|---|---|---|
| Название | ≤50 | С заглавной, не КАПСОМ. Идентично названию внутри игры (5.1.3). Уникально в каталоге (5.12). Избегать слов «игра»/«game» (6.5) |
| SEO-описание | 50–160 | |
| Об игре | 100–1000 | Точно отражает механики (8.2.2) |
| Короткое описание | ≤70 | С заглавной, не повторяет название, без «бесплатная», «на русском языке», без кавычек-обёртки |
| Как играть | 100–1000 | Полностью описывает управление (2.2): клавиатура/мышь И тач, если есть мобильные |
| Ключевые слова | ≤100 | Только строчные, через запятую, по теме (5.4) |
| Категории | ≤2 | обязательно |
| Теги | ≤20 | по теме |

Общие запреты: орфография/пунктуация языка (8.2.1); мат на любом языке (8.2.4);
повторяющиеся символы для набора длины и дублирование текста между полями (5.11).

## Визуалы
- Иконка: 512×512 PNG. Обложка: 800×470 PNG. Hero (опц.): 1560×520 PNG/JPG.
- Иконка/обложка: **НЕЛЬЗЯ скриншоты из игры** (5.6); без рамок и скруглённых углов (8.3.3);
  без системного UI, бейджей, рейтингов (8.3.4); без игрового UI (хелсбары и т.п.);
  текст не обрезан (8.3.1); отражает игру (8.3.2). Решение: постановочный рендер моделей игры + название.
- Слова на иконке/обложке/скриншотах/видео переводятся на язык локализации → делать версии по языкам
  или не использовать текст кроме названия.
- Чёрные поля допустимы только если это часть игры, а не паддинг масштабирования (5.9).

## Скриншоты
- Desktop: только альбомные. Mobile: альбомные или портретные (по ориентации игры).
- 16:9 / 9:16, длинная сторона 1280–2560 px (берём 1920×1080 / 1080×1920). JPEG или 24-bit PNG (без альфы!).
- Минимум 2 на каждую выбранную платформу (делаем 4–6).
- Реальный геймплей ≥70% площади (5.1.1.2).

## Видео
- Горизонтальное (обязательно): 16:9, MP4, высота ≥400, ≤28 с, ≤100 МБ.
- Вертикальное (опц.): 9:16, MP4, высота ≥400, ≤28 с, ≤100 МБ.
- Реальный геймплей ≥70% длительности (5.1.1.3).
- Промо-видео (опц., до 20): 1920×1080 / 1080×1920 рекоменд., минимум 1280×720 / 720×1280.

## Архив (тех.)
- ZIP, ≤100 МБ в распакованном виде, `index.html` в корне, без пробелов и кириллицы в именах файлов (1.21–1.22).
- Язык игры определяется через SDK автоматически (2.14). Соотношение сторон активной области ≤2:1 (1.6.2.2).
- Без абсолютных URL на S3 Яндекса (1.7). Реклама в ориентации игры (4.3).
- Видео в игре — через игровой плеер, не системный. Нет системного контекстного меню в игровой области.

## Языки
Основные рынки Яндекс Игр: ru, en, tr. Дополнительно популярны: de, es, pt, fr, it, pl, uk, kk, uz, be, ar, ja.
Объявлять язык в черновике можно только если игра реально на нём переведена через SDK.
