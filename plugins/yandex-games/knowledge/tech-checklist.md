# Тех. чек-лист Яндекс Игр (Unity WebGL)

Дополняй по итогам модерации (отказы → сюда и в lessons.md).

Быстрый старт аудита: `ygtool tech-scan` (плагин, модули, локализация, остатки старого API,
русские строки в коде). Строки в сценах/префабах (TMP-тексты) он не видит — их проверять отдельно.

## Установка PluginYG2 (если SDK нет) и миграция с PluginYG1
Документация: https://max-games.ru/plugin-yg/doc/ (перед установкой сверься с ней — меню и окна плагина
меняются между версиями; не выдумывай названия пунктов, читай доку или смотри в редакторе).
1. Пользователь скачивает актуальный PluginYG2 с официального сайта (ссылка в документации) и импортирует
   `.unitypackage` в проект. При миграции: сначала git-коммит, потом импорт PluginYG2.
2. Платформа — Yandex Games; модули — только нужные игре (см. agents/yandex-tech.md). Плагин сам добавит
   define-символы (`PLUGIN_YG_2`, `<Модуль>_yg`) и шаблон WebGL.
3. Код игры (делает агент):
   - реклама: показ interstitial в паузах между уровнями/матчами, rewarded — награда только в колбэке награды;
   - пауза/звук: включить в настройках плагина автопаузу на рекламе и при сворачивании; свою паузу не дублировать;
   - сохранения: прогресс в `YG2.saves` (+ `YG2.SaveProgress()` после изменений), а не только PlayerPrefs;
   - язык: модуль Localization или LocYG (берёт `YG2.envir.language` сам);
   - Gameplay API: `YG2.GameplayStart/Stop` на старте/паузе/конце раунда.
4. Миграция YG1: заменить API по маппингу ниже, удалить `Assets/YandexGame` только после того, как проект
   компилируется без него. Сцены с префабом YandexGame — заменить на префаб/настройки YG2.
5. Проверка в редакторе: симуляция плагина (язык, реклама, сохранения), затем сборка и запуск в черновике.

## SDK
- [ ] Подключён PluginYG2 (`Assets/PluginYourGames`, настройки `Resources/SettingsYG2.asset`). Старый
      PluginYG (`Assets/YandexGame`, класс `YandexGame`) — мигрировать, не держать оба.
- [ ] Нужные модули PluginYG2 стоят в `Modules/`: InterstitialAdv, RewardedAdv, Storage (сохранения),
      EnvirData, Localization (если языков >1), Leaderboards/Authorization — по фичам игры.
- [ ] Миграция YG1 → YG2 (проверено на реальном проекте):
      `YandexGame.SDKEnabled`→`YG2.isSDKEnabled`, `GetDataEvent`→`YG2.onGetSDKData`,
      `OpenFullAdEvent/CloseFullAdEvent`→`YG2.onOpenInterAdv/onCloseInterAdv`,
      `OpenVideoEvent/CloseVideoEvent/ErrorVideoEvent`→`YG2.onOpenRewardedAdv/onCloseRewardedAdv/onErrorRewardedAdv`,
      `RewardVideoEvent(int)`→`YG2.onRewardAdv(string id)`, `RewVideoShow(int)`→`YG2.RewardedAdvShow(string)`,
      `FullscreenShow()`→`YG2.InterstitialAdvShow()`, `YandexGame.savesData`→`YG2.saves`.
      Id наград стали строками — сравнивать через `.ToString()`.
- [ ] Вызывается GameReady (LoadingAPI.ready) после загрузки, когда игра готова к взаимодействию.
- [ ] Gameplay API: `YG2.GameplayStart()` / `YG2.GameplayStop()` при выходе из паузы / входе в паузу,
      меню, конце матча.
- [ ] Язык определяется через SDK (`environment.i18n.lang`) и переключает все тексты (2.14). Все языки из
      config.languages реально переведены, включая название игры. Захардкоженные строки в коде
      (`text = "Купить"`) = игра только на одном языке → заявлять в черновике только его.
- [ ] Сохранения: облачные (если отмечено в черновике) или локальные, прогресс не теряется при перезапуске.

## Реклама
- [ ] Interstitial не чаще разрешённого и не во время активного геймплея.
- [ ] На время любой рекламы: звук выключен (AudioListener.pause / volume), время на паузе, ввод заблокирован.
- [ ] Rewarded выдаёт награду только по событию onRewarded.
- [ ] После рекламы корректно возвращаются звук, время, курсор (lock/visible).
- [ ] Реклама в ориентации игры (4.3).

## Поведение
- [ ] Пауза и выключение звука при потере фокуса / сворачивании вкладки (visibilitychange).
- [ ] Нет системного контекстного меню в игровой области (правый клик), нет выделения текста/скролла страницы.
- [ ] Курсор: при pointer lock корректный выход по Esc, игра не ломается.
- [ ] Нет внешних ссылок, сторонних SDK рекламы/аналитики, абсолютных URL на S3 Яндекса (1.7).
- [ ] Видео внутри игры — через игровой плеер.
- [ ] Мобильные: тач-управление, полный экран, нет мелких кнопок; соотношение сторон активной области ≤2:1.

## Билд
- [ ] WebGL, сжатие Brotli/Gzip с decompression fallback, либо без сжатия.
- [ ] Распакованный размер ≤100 МБ, `index.html` в корне архива, имена без пробелов и кириллицы.
- [ ] Шаблон без лишнего (логотипы Unity не обязательны), фон загрузки корректный.
- [ ] Development Build выключен, нет дебаг-панелей/читов в релизе.
- [ ] PlayerSettings.productName = название игры (синхронно с черновиком).
